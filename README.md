# Movie Ticket Booking Application 🎬

## About Project
The Movie Ticket Booking Application allows users to explore available movies, check show timings, select their preferred seats, and book movie tickets easily.

## Features
- User registration and login.
- Browse available movies.
- View movie details.
- Check show timings.
- Select preferred seats.
- Book movie tickets.
- Manage bookings.

## Project Objective
To provide a simple and convenient platform for users to explore movies and book tickets online.
